# EAJ brand assets

Stand-in vector monogram drawn in the style of the EAJ logo (`eaj-primary.png`, Plan section 7.1).
When the official vector redraw is available, replace these files **and** the two path constants in
`resources/js/components/brand/eaj-mark.tsx` (used by the app, the splash screen and `public/favicon.svg`).

- `eaj-mark.svg` - full colour for dark backgrounds (white E, crimson A)
- `eaj-mark-light.svg` - for light backgrounds (navy E, crimson A)
- `eaj-mark-mono.svg` - single colour (currentColor); use below 24px
